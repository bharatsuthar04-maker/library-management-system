# Modern Library Management System

A desktop application built with Python, Tkinter, and SQLite for managing library inventory and book issuing. Features a modern, flat UI design without requiring external CSS or third-party UI libraries.

## Features
* **Authentication:** Secure admin login system.
* **Dashboard Overview:** Live statistics of total books, members, and active issues.
* **Book Management:** Add and remove books with quantity tracking.
* **Member Management:** Register and remove library members.
* **Issue/Return System:** Track borrowed books with automatic 14-day due date calculation and dynamic inventory updating.

## Prerequisites
* Python 3.x installed on your machine.
* No external pip packages required (uses built-in `tkinter` and `sqlite3`).

## How to Run
1. Clone the repository: `git clone https://github.com/YOUR-USERNAME/library-management-system.git`
2. Navigate to the directory: `cd library-management-system`
3. Run the application: `python main.py` (replace `main.py` with your actual filename)
